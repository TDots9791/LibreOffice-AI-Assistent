AI-ассистент для LibreOffice (Writer, Calc, Impress, Draw) в виде расширения `.oxt`.
В отличие от обычных «чат-плагинов», агент **сам видит содержимое документа и сам его
редактирует**: читает диапазоны ячеек и текст документа, пишет формулы, строит диаграммы,
собирает сводные таблицы — по обычному запросу человеческим языком.

> Протестировано: **Linux (Fedora), LibreOffice 26.8.1.1 (flatpak)**. Установка на Windows
> и macOS поддерживается (см. [Установку](#установка)), на этих системах пока не проверялась.

## Что это

Плавающая панель чата внутри LibreOffice. В базовом режиме это обычный AI-чат с
потоковым выводом и быстрыми действиями над текстом. С включённой галочкой
**«Работать с документом (агент)»** ассистент превращается в агента: модель через
инструменты сама осматривает документ, вносит изменения и проверяет результат —
без копирования текста в чат вручную.

## Возможности

- **Агент с инструментами** (Writer и Calc): чтение и правка живого документа,
  каждый шаг виден в чате.
- **11 быстрых действий**: Чат, Улучшить текст, Грамматика и орфография, Выжимка,
  Перевод (язык цели настраивается), Объяснить, Продолжить текст, Сократить,
  Расширить, Официальный стиль, Маркированный список.
- **Вставка результата**: «Вставить» (в курсор), «Заменить» (выделение), «Копировать».
- **Потоковый вывод** ответа и кнопка «Стоп»; история диалога (8 ходов, настраивается).
- **17 пресетов провайдеров** + произвольный endpoint; живой список моделей с сервера
  (кнопка Refresh и авто-подгрузка после теста подключения).
- **Окно панели**: изменяемый размер мышью за края и углы (нативный, средствами ОС),
  панель прижимается к правой колонке LibreOffice и следит за окном офиса.
- **Интерфейс**: русский / английский / китайский (авто-определение по локали,
  вручную — `"ui_lang": "ru|en|zh"` в config.json).
- Только стандартная библиотека Python (никаких pip-зависимостей) — работает со
  встроенным Python LibreOffice.

## Агент и инструменты

Галочка «Работать с документом» включает агентный цикл: модель получает набор
инструментов и сама решает, что вызвать; результат каждого вызова возвращается
модели, пока задача не будет решена (до 12 ходов, настраивается — `agent_max_steps`).

Инструменты в **Calc**:

| Инструмент | Что делает |
|---|---|
| `calc_info` | листы книги и занятые диапазоны |
| `read_range` | значения ячеек (+ опционально формулы) |
| `write_range` | запись массива значений в диапазон |
| `set_formula` | запись формул в ячейки/диапазон |
| `sort_range` | сортировка по одному или нескольким полям |
| `format_range` | жирный/курсив, цвет фона и шрифта, числовой формат |
| `create_chart` | диаграммы: столбчатая, линейчатая, график, круговая, площадь, точечная |
| `create_pivot` | сводные (консолидированные) таблицы: строк/столбцы/данные, агрегации sum, count, average, min, max |
| `find_replace` | поиск и замена по листу или всей книге |

Инструменты в **Writer**: статистика, чтение всего документа и выделения, замена
выделения, вставка в курсор, поиск-замена по документу.

Каждая правка — обычная операция LibreOffice и откатывается через **Ctrl+Z**.
Если модель ошиблась с аргументами, она получает текст ошибки и исправляется сама.

## Провайдеры

| Провайдер | API-стиль | Где взять ключ |
|---|---|---|
| **Z.ai Coding Plan (GLM)** — проверен в работе | OpenAI | [z.ai/manage-apikey](https://z.ai/manage-apikey/apikey-list) |
| Z.ai Open Platform | OpenAI | там же |
| **Anthropic Claude** | Messages | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| **OpenAI (GPT)** | OpenAI | [platform.openai.com](https://platform.openai.com/api-keys) |
| **OpenAI Codex** | Responses | там же |
| Google Gemini | OpenAI-слой | [aistudio.google.com](https://aistudio.google.com/apikey) |
| OpenRouter, DeepSeek, Mistral, Groq, xAI, Together, Fireworks, Perplexity | OpenAI | консоли провайдеров |
| Ollama, LM Studio (локально, без ключа) | OpenAI | — |
| Custom | OpenAI | любой совместимый endpoint |

Все 17 пресетов покрыты тестами подключения (по своему API-стилю, на локальном моке
API: `tests/test_providers.py`). Для reasoning-моделей OpenAI (`o1/o3/o4`, `gpt-5*`)
расширение само убирает `temperature` и шлёт `max_completion_tokens`.

Агентный режим требует провайдера с function calling — это все OpenAI-совместимые
стили (14 из 17 пресетов, включая Z.ai GLM). Claude и Codex пока работают в обычном
чат-режиме (инструменты для этих стилей — в планах).

## Установка

На всех трёх системах установка одинаковая — через менеджер расширений:

1. Скачайте `dist/sphaera-lo-ai-assistant.oxt` (или соберите сами: `./build.sh`).
2. LibreOffice → **Сервис ▸ Управление расширениями… ▸ Добавить** → выберите файл.
3. Полностью перезапустите LibreOffice — появится меню **AI-ассистент** и кнопка на панели.

Дополнительно для Linux есть скрипт: `./install.sh` (понимает flatpak-установку;
LibreOffice во время установки должен быть закрыт).

Требования: LibreOffice с поддержкой Python-скриптов (включена по умолчанию
в стандартных установщиках Windows, macOS и Linux).

## Быстрый старт

1. **AI-ассистент ▸ Настройки…**: выберите пресет — адрес и модель подставятся
   автоматически → вставьте API-ключ → **Test connection** → **Save**.
2. **AI-ассистент ▸ Открыть панель…** — панель прижмётся к правой колонке окна
   (или тяните её за край в удобное место).
3. Задайте вопрос или выберите действие. С галочкой «Работать с документом»
   агент сам читает и правит документ: «построй график по столбцам B:D»,
   «сделай сводную таблицу продаж по менеджерам», «улучши второй абзац».

## Безопасность

API-ключи хранятся **только локально** в JSON-конфиге с правами `0600`
(`…/user/config/lo-ai-assistant/config.json` в профиле LibreOffice; вне офиса —
`$APPDATA/lo-ai-assistant` или `$XDG_CONFIG_HOME/lo-ai-assistant`). Ключи передаются
лишь выбранному вами API-провайдеру. Не коммитьте конфиг в git.

**Про персональные данные** — см. предупреждение в начале страницы: в агентном режиме
и при включённом контексте содержимое документа уходит выбранному AI-провайдеру.
Перед работой с документами, содержащими ПДн, обезличьте их — например,
[Incognito Web](https://iustitia.tech/incognito/demo/) или
[Incognito Desktop](https://iustitia.tech/incognito/).

## Ограничения

- **LibreOffice 24.2 (Windows)**: если после установки расширение «молчит» (меню есть,
  клики ничего не дают) — проверьте, что установлен компонент **Python Scripting
  Support** (в стандартном установщике включён по умолчанию; переустановите LO с ним),
  и обновите LibreOffice: 24.2 завершила жизненный цикл в мае 2024, расширение
  тестируется на 26.8. Python-код расширения работает на встроенном Python — без него
  ассистент не запускается и не выдаёт ошибок.
- Агентный режим (инструменты) реализован для OpenAI-совместимых провайдеров;
  Anthropic/Codex — обычный чат без инструментов.
- В LibreOffice **flatpak** удалённый URP-мост нестабилен — особенность сборки,
  расширение работает in-process и её не касается.
- Impress/Draw поддержаны в базовом сценарии (чтение/вставка текста фигур);
  инструменты уровня Calc для них — в планах.
- Windows и macOS: установка поддерживается, но пока не проверялась на реальных
  машинах (сообщения о проблемах приветствуются).
