# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.16.0] — 2026-10-05

### Изменено
- **Панель очищена**: кнопка «Настройки…» убрана из панели (настройки остаются в меню
  «AI-ассистент ▸ Настройки…»); комбобоксы провайдера и модели стали шире — выбранная
  модель видна целиком.
- **«Клей» больше не навязывает размер окна**: панель следует за окном LibreOffice
  только позицией; размер меняется лишь пользователем (нативный ресайз).
- Раскладка пересчитывается по фактическим размерам из события ресайза (в лог пишется
  расхождение с getPosSize для диагностики на Wayland).

### Исправлено
- «Поле ввода уже поля ответа»: при раскладке ширина ввода и чата теперь согласованы
  с правым блоком кнопок.

## [1.15.0] — 2026-10-05

### Исправлено
- Раскладка применяется **напрямую через контролы** (`UnoControl` реализует
  `XWindow` — `setPosSize`/`getPosSize` в пикселях); вариант с моделями контролов
  (1.14.0) у живого диалога не срабатывал. Релайаут по-прежнему вызывается явно после
  каждого программного изменения размера.

### Изменено
- Убраны из окна служебные элементы: подсказка о размере окна и поле языка перевода
  («English») — язык перевода теперь берётся из языка интерфейса (RU→Russian и т.д.)
  и при желании задаётся ключом `target_lang` в config.json. Действие «Перевести»
  работает как прежде.

## [1.14.0] — 2026-10-05

### Исправлено
- **Раскладка панели** («всё уехало за границы окна, отступы, криво»): контролы
  раскладываются в диалоговых юнитах через модели (VCL сам отображает их в пиксели) —
  исключён рассинхрон пикселей и юнитов; релайаут вызывается явно после каждого
  программного изменения размера (сохранённый размер, «клей»), а не только по событию
  окна; слушатель ресайза вешается до первых ресайзов.

## [1.13.1] — 2026-10-04

### Исправлено
- **Меню «молчит» на любой ОС**: диспетчер `service:`-URL вызывает у компонента метод
  `XJobExecutor::trigger()`, а не `execute()` — pyuno не находил метод, исключение
  глоталось фреймворком. Метод переименован; клики по меню теперь открывают панель
  и настройки (проверено запуском через макросы на Windows 11 / LO 24.2.4.2 и той же
  кодовой базой на Linux / LO 26.8).

### Документация
- README (RU/EN): раздел про тишину на LibreOffice 24.2 Windows — проверка компонента
  Python Scripting Support и рекомендация обновления (24.2 EOL с мая 2024).

## [1.13.0] — 2026-10-03

### Добавлено
- Публикация репозитория; README на трёх языках (RU/EN/中文) с ярким предупреждением
  о том, что модель видит персональные данные из документов (ссылки на Incognito
  Web/Desktop); тэги и описание репозитория; wiki (Home и справочник инструментов
  на трёх языках).
- Тест подключения всех 17 пресетов провайдеров (`TestAllPresets`, локальный мок API).

### Изменено
- Интерфейс: убраны служебные надписи (версия в статусе); кнопки фиксированного
  размера, прижатые к краям окна, — надписи не обрезаются ни при каком масштабе;
  тянется только содержимое (чат, ввод, статус, подсказка).
- Скан и чистка личных данных (захардкоженные пути, отладочные скрипты, `__pycache__`).

## [1.12.0] — 2026-10-03

### Изменено
- **Универсальная установка на Windows/macOS/Linux**: меню и кнопка тулбара переведены
  с Basic-моста (требовал посева в профиль) на компонентный маршрут
  `service:org.sphaera.lo.ai.panel.impl` / `.settings.impl`; установка — только через
  Extension Manager.

## [1.11.0] — 2026-10-03

### Добавлено
- **Агент с инструментами над живым документом** (Writer и Calc): модель сама
  осматривает документ, вносит правки и проверяет результат.
  - 15 инструментов: чтение/запись диапазонов, формулы, сортировка, форматирование,
    диаграммы (6 типов), сводные таблицы, поиск-замена; Writer — чтение документа и
    выделения, замена, вставка, поиск-замена.
  - Агентный цикл с function calling (OpenAI-совместимые провайдеры, 14 из 17
    пресетов), шаги агента видны в чате; лимит ходов с форс-итогом; ошибки
    инструментов возвращаются модели текстом для самокоррекции.
  - Контекст документа без выделения: весь текст Writer, превью занятого диапазона
    Calc с именами листов.
- Галочка «Работать с документом (агент)», `agent_enabled`/`agent_max_steps` в конфиге.
- Тесты агентного цикла на хостовом Python без LibreOffice (`tests/test_agent.py`).

## [1.10.0] — 2026-10-03

### Изменено
- **Нативное изменение размера окна** (свойство `Sizeable` модели диалога →
  `WB_SIZEABLE`): за края и углы мышью, живая перекладка контролов, минимальный
  размер 320×260, размер сохраняется в конфиг. Самодельный драг за края удалён.

## [1.0.0 – 1.9.2] — 2026-09-29

### Добавлено
- Первая рабочая версия: плавающая панель-чат с потоковым выводом и кнопкой «Стоп»,
  11 быстрых действий (улучшить/грамматика/выжимка/перевод/…), вставка результата в
  документ (Writer/Calc/Impress/Draw) и копирование.
- Мультипровайдерность: пресеты Z.ai (Coding Plan и Open Platform), Anthropic, OpenAI,
  Codex (Responses API), Gemini, OpenRouter, DeepSeek, Mistral, Groq, xAI, Together,
  Fireworks, Perplexity, Ollama, LM Studio, custom; живой список моделей, тест
  подключения; специальная обработка reasoning-моделей OpenAI.
- Настройки: ключи локально (config.json, 0600), температура/max tokens/таймаут,
  системный промпт, стриминг вкл/выкл, язык интерфейса (RU/EN/中文).
- Диагностика: полный трейсбек в диалоге ошибок и error.log.
- Изменяемый размер и «клей» правого края (пошаговые механизмы, заменённые нативным
  ресайзом в 1.10.0).
